# React Native MCQ

> A simple multiple-choice quiz app built with React Native .
> Users can take quizzes, view scores.

---

## Features

-Home Screen with start button
-Timed MCQ quizzes with 4 options
-On time shows results
-Track user results at the end
-Internet check ,if go offline quiz stopped
-fetch from API
